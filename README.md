# (mino) — mino.inc website

Rebuild of mino.inc. Static site, no build step.

- `index.html` — page structure and copy
- `styles.css` — design system, layout, CSS animation
- `main.js` — motion (GSAP + ScrollTrigger, Lenis smooth scroll), cursor, hover effects
- `assets/` — cinematic imagery generated with Nano Banana 2.1

Run locally: `python3 -m http.server` and open http://localhost:8000.
Deploy: any static host (Vercel, Netlify, GitHub Pages).

Compounded preparations are not FDA-approved. (mino) compounds under Section 503A for physician-directed, patient-specific prescriptions.
